# TGIU 크레인 실습

크레인 운전석에서 위에서 아래로 내려다보는 시점으로 진행하는 컨테이너 물류 교육용 모바일 게임입니다.

> 태웅로직스 직원이 만든 비공식 교육용 게임입니다. 회사의 공식 콘텐츠가 아니며, 수치와 규칙은 교육용으로 단순화했습니다.

## 조작 방식
홈 화면에서 고릅니다.

- **컨트롤러 (기본)**: 크레인을 직접 운전합니다.
  - 트롤리 ◀ ▶: 크레인 빔을 따라 좌우 이동 (관성이 있어 고수일수록 미끄러짐)
  - 호이스트 ▲ ▼: 스프레더 올리기/내리기. 아래 컨테이너에 닿으면 착지
  - 잠금/해제: 착지 + 열 중앙 정렬(초보 ±8, 중수 ±6, 고수 ±3.5)일 때만 동작. 스프레더 색이 노랑(공중) → 초록(착지·정렬) → 빨강(정렬 불량)
  - 호이스트를 충분히 올리지 않고 트롤리를 옮기면 더 높은 열에 막히며 "충돌 경고"(중수·고수 −2점)
  - 키보드: 방향키 또는 WASD + 스페이스 / 게임패드: 왼쪽 스틱·십자키 + A 버튼
- **탭**: 열을 누르면 크레인이 자동으로 이동합니다. 작업 순서를 익힐 때 좋습니다.

가로 화면에서는 운전석 화면이 왼쪽, VMT가 오른쪽에 배치됩니다.

## 모드 1. 야드 이적·반출 (RTG 트랜스퍼 크레인)
트럭이 와서 반출 오더의 컨테이너를 기다립니다. 대상 위에 쌓인 컨테이너를 다른 열로 **이적**한 뒤 대상을 트럭에 실어 **반출**합니다.

- 조작: 열을 눌러 맨 위 컨테이너를 집고, 다른 열을 눌러 내려놓기. 대상을 집었으면 트럭 차선을 누르기.
- 하단 VMT(차량 탑재 단말기)에 오더, 야드 위치(`A03-15-04-2` = 블록-베이-열-단), 베이 단면이 표시됩니다.
- 감점: 불필요한 이적(−5), 반출 대상 위에 적재(−10), 다음 반출 예정 컨테이너 위에 적재 = 재취급 유발(−8), 고수에서 트럭 대기 초과(탭 45초 / 컨트롤러 90초, −10)

| 난이도 | 야드 | 반출 오더 | 화면 힌트 |
|---|---|---|---|
| 초보 | 4열 × 3단 | 2건 | 대상 + 내려놓기 좋은 열 표시 |
| 중수 | 6열 × 4단 | 3건 | 대상만 표시 |
| 고수 | 6열 × 5단 | 4건 | 표시 없음, 트럭 대기 45초 제한 |

## 모드 2. 본선 선적 (STS 안벽 크레인)
트럭으로 도착하는 수출 컨테이너를 선박 베이 13 갑판에 싣습니다. 항로는 부산 → 상하이(SHA) → 닝보(NGB) → 싱가포르(SIN)입니다.

- 조작: 실을 열(Row)을 누르면 크레인이 트럭에서 집어 그 열에 싣습니다. 다음 2개 컨테이너를 미리 볼 수 있습니다.
- 본선 위치는 `13-02-84`(베이-열-단) 형식이며, 열은 중앙에서 바깥으로 좌현 짝수 / 우현 홀수, 갑판 단은 82부터 2씩 올라갑니다.
- 감점: Overstow(나중 항구 화물이 먼저 항구 화물 위, −15), 중량 역적재(−8), 리퍼 슬롯 위반(−15), 종료 시 횡경사 한도 초과(−20)

| 난이도 | 베이 | 선적 수 | 규칙 |
|---|---|---|---|
| 초보 | 5열 × 3단 | 10개 | 양하항 2곳, Overstow 안 나는 열 표시 |
| 중수 | 6열 × 4단 | 16개 | 양하항 3곳 + 무게 |
| 고수 | 6열 × 4단 | 20개 | + 냉동 컨테이너 플러그 열, 횡경사 2° 이내 |

결과 화면에서 점수와 별점, 실수 유형별 설명(작업 복기)을 보여 줍니다. 최고 점수는 작업·난이도별로 브라우저에 저장됩니다.

## 파일
- `index.html`: 크레인 실습 게임 (단일 파일, 라이브러리 없음)
- `stack.html`: 이전 버전 "컨테이너 쌓기" 원터치 게임

## 실행 / 배포
- 로컬: `index.html`을 브라우저로 열면 바로 실행됩니다.
- 휴대폰: 저장소 **Settings → Pages**에서 이 브랜치와 `/ (root)`를 선택하면 주소가 생깁니다.
