# 컨테이너 쌓기 (Container Stack)

야간 부산 컨테이너 터미널을 배경으로 한 가벼운 모바일 원터치 게임입니다.
갠트리 크레인이 좌우로 옮기는 **TGIU(태웅로직스) 컨테이너**를 탭 한 번으로 내려 최대한 높이 쌓으세요.

> 태웅로직스 직원이 만든 비공식 사내 게임입니다. 회사의 공식 콘텐츠가 아닙니다.

## 난이도
| 모드 | 크레인 속도 (시작 → 최대) | "정확" 판정 | 폭 회복 | 시작 폭 | 특징 |
|---|---|---|---|---|---|
| 초보 | 85 → 210 | ±8px | 2연속, +14 | 220 | 천천히, 넉넉하게 |
| 중수 | 115 → 320 | ±4px | 3연속, +10 | 200 | 기본 |
| 고수 | 150 → 430 | ±2.5px | 4연속, +6 | 170 | 속도가 불규칙하게 출렁임 |

최고 기록은 모드별로 따로 저장됩니다.

## 플레이 방법
- **탭 / 스페이스바**: 컨테이너 내리기
- 아래 컨테이너와 어긋난 부분은 잘려 나가고, 다음 컨테이너는 그만큼 좁아집니다.
- 거의 정확하게 내리면 "정확!" 판정, 연속으로 맞추면 폭이 다시 넓어집니다(모드별 기준은 위 표).
- 단수가 올라갈수록 크레인 속도가 빨라집니다.
- 최고 기록은 모드별로 브라우저(localStorage)에 저장됩니다.

컨테이너에 찍힌 번호(예: `TGIU 496351 9`)는 실제 ISO 6346 규칙으로 계산한 체크 디지트를 사용하고,
`45G1`(40ft 하이큐브) / `22G1`(20ft 일반) 사이즈·타입 코드도 표시됩니다.

## 구조
- `index.html` 한 파일 (HTML + CSS + Canvas JS). 빌드 도구·라이브러리 없음.
- 웹폰트(Google Fonts)만 외부에서 불러오며, 없어도 시스템 폰트로 동작합니다.

## 실행 / 배포
- 로컬: `index.html`을 브라우저로 열면 바로 실행됩니다.
- 휴대폰에서 플레이하려면 GitHub Pages를 켜면 됩니다:
  저장소 **Settings → Pages → Branch** 에서 배포 브랜치와 `/ (root)` 선택 → 저장.
- 휴대폰 브라우저의 "홈 화면에 추가"를 쓰면 앱처럼 전체 화면으로 실행됩니다.
